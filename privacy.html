1. 수집하는 정보

던파노트(이하 "사이트")는 회원가입이 없으며, 이름·연락처 같은 개인정보를 직접 수집하지 않습니다. 캐릭터 검색에 입력한 캐릭터 이름은 네오플 오픈 API 조회에만 사용하고 저장하지 않습니다.

2. 브라우저에 저장하는 정보

"내 최근 검색" 기능을 위해 최근 조회한 캐릭터 목록을 이용자의 브라우저(localStorage)에만 저장합니다. 이 정보는 사이트 서버로 전송되지 않으며, 브라우저의 사이트 데이터를 삭제하면 지워집니다.

3. 광고와 쿠키

사이트는 Google 애드센스를 통해 광고를 게재할 수 있습니다. Google을 포함한 제3자 광고 사업자는 쿠키를 사용해 이용자의 이전 방문 기록을 바탕으로 광고를 표시할 수 있습니다. 이용자는 Google 광고 설정에서 맞춤 광고를 끌 수 있으며, Google의 광고 쿠키 사용에 대한 자세한 내용은 Google 광고 정책에서 확인할 수 있습니다.

4. 외부 서비스

  • 게임 데이터: 네오플 오픈 API (Powered by Neople Open API)
  • 사이트 호스팅: GitHub Pages
  • 실시간 조회 중계: Cloudflare Workers
  • 글꼴: Google Fonts

각 서비스는 기술적인 이유로 접속 IP 등 접속 기록을 처리할 수 있으며, 이는 각 서비스의 개인정보처리방침을 따릅니다.

5. 저작권 안내

사이트는 던전앤파이터 공식 사이트가 아닌 팬 정보 사이트입니다. 던전앤파이터의 상표, 게임 이미지와 데이터의 권리는 (주)네오플에 있습니다.
